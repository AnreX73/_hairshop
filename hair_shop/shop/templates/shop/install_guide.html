Установите наш магазин как приложение

Получайте уведомления о заказах в один клик

🤖 Инструкция для Android

  1. Откройте наш сайт в браузере Google Chrome.
  2. В правом верхнем углу нажмите на три точки ⋮ — откроется меню.
  3. Выберите пункт «Установить приложение» или «Добавить на экран "Домой"».
  4. Нажмите «Установить» — иконка появится среди ваших приложений.

✅ Готово! После установки вы будете получать push-уведомления о статусе вашего заказа.

🍏 Инструкция для iPhone / iPad

  1. Откройте наш сайт в Safari (другие браузеры на iOS не подходят для установки).
  2. Внизу экрана нажмите на иконку «Поделиться» ⎔ (квадрат со стрелкой вверх).
  3. Пролистайте нижнюю панель вправо и выберите функцию «На экран "Домой"».
  4. При желании отредактируйте название ярлыка и нажмите «Добавить».

⚠️ Важно для iOS: Чтобы уведомления работали, обязательно разрешите их отправку при первом открытии сайта. Система Apple спросит разрешение только один раз — не пропустите этот момент!

💡 Если вы случайно нажали «Не разрешать» — удалите ярлык с экрана «Домой», заново откройте сайт в Safari и повторите установку. Система спросит разрешение снова.
